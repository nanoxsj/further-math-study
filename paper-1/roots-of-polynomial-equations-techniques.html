1.1 Common problem-solving techniques

Roots of polynomial equations

常用解题技巧：根与系数、对称式、幂和、倒数根与根的变换。
重要

This page is a problem-solving guide for 1.1 Roots of polynomial equations. Use it together with the textbook examples and past-paper questions.

1. Start with the right notation

Before calculating, write the polynomial in a standard form and identify the number of roots.

For az^n+bz^{n-1}+\cdots=0, check the leading coefficient first. Vieta’s formulae use signed coefficients divided by the leading coefficient. If convenient, divide through by a and use the monic form.

For a cubic, define e_1=\alpha+\beta+\gamma,\qquad e_2=\alpha\beta+\beta\gamma+\gamma\alpha,\qquad e_3=\alpha\beta\gamma. Then read these values directly from the equation: e_1=-\frac ba,\qquad e_2=\frac ca,\qquad e_3=-\frac da.

For a quartic, use e_1=\alpha+\beta+\gamma+\delta=-\frac ba, e_2=\sum\alpha\beta=\frac ca,\qquad e_3=\sum\alpha\beta\gamma=-\frac da,qquad e_4=\alpha\beta\gamma\delta=\frac ea.

2. Convert the target expression before substituting

Most symmetric-function questions become short once the target is rewritten in terms of e_1,e_2,e_3,e_4.

Squares

For any set of roots, \sum\alpha^2=\left(\sum\alpha\right)^2-2\sum\alpha\beta.

For a cubic this becomes \alpha^2+\beta^2+\gamma^2=e_1^2-2e_2.

Cubes

Use the identity \sum\alpha^3=e_1^3-3e_1e_2+3e_3.

The safest derivation is to expand e_1^3=(\alpha+\beta+\gamma)^3 and collect the terms \alpha^3+\beta^3+\gamma^3.

Products of pairs

For a cubic, \alpha^2\beta^2+\beta^2\gamma^2+\gamma^2\alpha^2=e_2^2-2e_1e_3.

This is usually faster than expanding each term separately.

A reliable workflow

  1. Write the basic symmetric values from the polynomial.
  2. Rewrite the requested expression using e_1,e_2,e_3,e_4.
  3. Substitute only at the last line.
  4. Check that the final expression is unchanged if the roots are relabelled.

If the expression contains an individual root, such as \alpha^2+\beta, it is not symmetric. Do not force a symmetric-function formula onto it; use the extra information in the question.

3. Use the polynomial to reduce high powers

If \alpha is a root of z^3+pz^2+qz+r=0, then \alpha^3=-p\alpha^2-q\alpha-r.

The same relation holds for \beta and \gamma. Adding the three equations gives S_3+pS_2+qS_1+3r=0, where S_k=\alpha^k+\beta^k+\gamma^k.

For n\geqslant3, S_n+pS_{n-1}+qS_{n-2}+rS_{n-3}=0.

The term 3r appears when n=3 because S_0=3. This is a common place to lose a mark.

Efficient order of work

For a cubic:

S_0=3,\qquad S_1=-p,\qquad S_2=p^2-2q.

Then use the recurrence successively. Do not expand \alpha^4, \alpha^5 and so on separately; that repeats the same work three times.

For a quartic z^4+pz^3+qz^2+rz+s=0, use S_n+pS_{n-1}+qS_{n-2}+rS_{n-3}+sS_{n-4}=0\qquad(n\geqslant4), with S_0=4.

4. Handle negative powers with reciprocal roots

If the constant term is non-zero, no root is zero. Set w=\frac1z.

For az^3+bz^2+cz+d=0, substitute z=1/w and multiply by w^3: d w^3+c w^2+bw+a=0.

The coefficients are reversed. The roots of this new equation are \frac1\alpha,\quad\frac1\beta,\quad\frac1\gamma.

This converts \alpha^{-1}+\beta^{-1}+\gamma^{-1} into an ordinary sum of roots of the reciprocal equation. It also converts negative power sums into the positive power sums of the reciprocal roots.

Direct shortcut

For a cubic, \sum\frac1\alpha=\frac{e_2}{e_3},\qquad \sum\frac1{\alpha\beta}=\frac{e_1}{e_3},\qquad \frac1{\alpha\beta\gamma}=\frac1{e_3}.

Use the reciprocal equation when the question asks for several negative powers; use the shortcut when only one low-power expression is required.

5. Form an equation for transformed roots

The first decision is whether the new roots are a simple linear transformation or a nonlinear transformation.

Linear transformation: w=mz+c

Substitute z=\frac{w-c}{m} into the original equation and multiply through by the required power of m to remove fractions.

For example, if the old equation is P(z)=0 and the new roots are m\alpha+c, m\beta+c, use P\left(\frac{w-c}{m}\right)=0.

This method is usually faster and less error-prone than calculating all new symmetric functions.

Squared roots

If the new roots are \alpha^2,\beta^2,\gamma^2, let w=z^2. Use the original equation to eliminate odd powers or calculate \alpha^2+\beta^2+\gamma^2=e_1^2-2e_2, \alpha^2\beta^2+\beta^2\gamma^2+\gamma^2\alpha^2=e_2^2-2e_1e_3, \alpha^2\beta^2\gamma^2=e_3^2.

The required cubic is therefore w^3-(\sum\alpha^2)w^2+(\sum\alpha^2\beta^2)w-\alpha^2\beta^2\gamma^2=0.

Reciprocal and shifted reciprocal roots

For roots such as 1/\alpha+c, first form the reciprocal-root equation, then apply the linear transformation w=u+c. Separating the two steps prevents sign and coefficient-order errors.

6. Find unknown coefficients efficiently

When an equation contains an unknown coefficient, use every independent piece of information in this order:

  1. Use the given root to substitute into the polynomial.
  2. Use a sum or product of roots with Vieta’s formulae.
  3. Use a repeated-root condition only if the question states or implies a repeated root.
  4. Solve the resulting simultaneous equations and substitute back into the original equation.

If one root is known, factor out the corresponding linear factor. For a monic cubic with root r, P(z)=(z-r)(z^2+uz+v). Comparing coefficients is often quicker than solving a full cubic.

7. Common errors checklist

  • Check the alternating sign pattern: -,+,-,+ for the basic symmetric functions.
  • Do not forget to divide by the leading coefficient.
  • In a power-sum recurrence, remember S_0 equals the number of roots.
  • Combine terms only after expanding; do not confuse \sum\alpha\beta with (\sum\alpha)(\sum\beta).
  • For reciprocal roots, confirm the constant term is non-zero.
  • After forming a new equation, check its leading coefficient, sum of roots and product of roots.
  • Keep the variable names clear: z for an old root and w for a transformed root.

8. Exam-ready answer structure

For a calculation question, a clear answer normally follows this order:

  1. State the relevant Vieta values.
  2. State the identity, recurrence or substitution being used.
  3. Show the substitution and the main algebraic step.
  4. Give the exact answer first, followed by a decimal only when requested.
  5. For a new equation, state that its roots are exactly the transformed roots and write the equation in a standard form.

This structure makes the method visible and matches the mark-by-mark style used in Cambridge mark schemes.
