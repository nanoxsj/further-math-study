2.6 Differential equations

积分因子 · 齐次与非齐次二阶方程 · 代换法

CIE 9231 Paper 2，依据 2026–2027 syllabus 与 Collins Further Pure Mathematics 2 Chapter 6。
重要本节考纲要求

考生需要能够：

  1. 求一阶线性微分方程的积分因子，并用积分因子求通解；
  2. 理解 complementary function（CF）与 particular integral（PI）的含义，并知道通解是 CF 与 PI 之和；
  3. 求一阶或二阶常系数线性微分方程的 complementary function（辅助方程有互异实根、重根或共轭复根三种情形）；
  4. 在多项式、\(ae^{bx}\)、\(a\cos px+b\sin px\) 适用时写出并求出 particular integral；其他简单情形给定 PI 形式后求系数；
  5. 使用给定代换把微分方程化为常系数线性方程或可分离变量的一阶方程；
  6. 用初始条件求特解，并解释解在模型中的含义。

学习路线

1. 教材知识点

1.1 First-order linear differential equations

一阶线性方程可写成

\[ \frac{\mathrm dy}{\mathrm dx}+P(x)y=Q(x). \]

乘以积分因子

\[ \boxed{R(x)=e^{\int P(x)\,\mathrm dx}}, \]

左边成为完全导数：

\[ \frac{\mathrm d}{\mathrm dx}\bigl(R(x)y\bigr)=R(x)Q(x), \]

然后两边积分即可。

1.2 Complementary functions for constant-coefficient equations

对 \(a\dfrac{\mathrm d^2y}{\mathrm dx^2}+b\dfrac{\mathrm dy}{\mathrm dx}+cy=0\)，解辅助方程

\[ ar^2+br+c=0. \]

三种情形：

  • 互异实根 \(r_1,r_2\)：\(y=Ae^{r_1x}+Be^{r_2x}\)；
  • 重根 \(r\)：\(y=e^{rx}(A+Bx)\)；
  • 共轭复根 \(a\pm\mathrm ib\)：\(y=e^{ax}(A\cos bx+B\sin bx)\)。

1.3 Particular integrals

对非齐次方程 \(a\dfrac{\mathrm d^2y}{\mathrm dx^2}+b\dfrac{\mathrm dy}{\mathrm dx}+cy=f(x)\)，根据 \(f(x)\) 选择 PI 形式：

  • \(f(x)\) 为 \(n\) 次多项式：PI 取 \(n\) 次多项式；
  • \(f(x)=ae^{bx}\)：PI 取 \(ke^{bx}\)；
  • \(f(x)=a\cos px+b\sin px\)：PI 取 \(p\cos px+q\sin px\)。

若所选形式已在 CF 中出现，则乘以 \(x\)；若仍重复，再乘以 \(x^2\)。

1.4 Substitutions

给定代换时，先通过链式法则把 \(\dfrac{\mathrm dy}{\mathrm dx}\)（必要时还有 \(\dfrac{\mathrm d^2y}{\mathrm dx^2}\)）换成新变量，再化简：

  • \(x=e^t\)：\(\dfrac{\mathrm dy}{\mathrm dx}=e^{-t}\dfrac{\mathrm dy}{\mathrm dt}\)，可处理 Euler 型方程；
  • \(y=ux\)：\(\dfrac{\mathrm dy}{\mathrm dx}=u+x\dfrac{\mathrm du}{\mathrm dx}\)，可把齐次型化为可分离变量；
  • \(v=y^n\)：\(\dfrac{\mathrm dv}{\mathrm dx}=ny^{n-1}\dfrac{\mathrm dy}{\mathrm dx}\)，可把 Bernoulli 型化为线性方程。

2. Textbook Examples

Example 1 · Page 124

Show that each of these equations can be written in the form \(\dfrac{\mathrm dy}{\mathrm dx}+P(x)y=Q(x)\):

(a) \(\dfrac{\mathrm dy}{\mathrm dx}=3x^2y+e^x\);

(b) \(\dfrac{\mathrm dy}{\mathrm dx}=\dfrac1{3x}y+2x\);

(c) \(\dfrac{\mathrm dy}{\mathrm dx}=\ln x\,(y+\sqrt x)\).

Show solution

(a) Subtract \(3x^2y\) from both sides:

\[ \boxed{\frac{\mathrm dy}{\mathrm dx}-3x^2y=e^x}, \]

so \(P(x)=-3x^2\), \(Q(x)=e^x\).

(b) Subtract \(\dfrac1{3x}y\) from both sides:

\[ \boxed{\frac{\mathrm dy}{\mathrm dx}-\frac1{3x}y=2x}, \]

so \(P(x)=-\dfrac1{3x}\), \(Q(x)=2x\).

(c) Expand the right-hand side:

\[ \frac{\mathrm dy}{\mathrm dx}=y\ln x+\sqrt x\ln x, \]

so

\[ \boxed{\frac{\mathrm dy}{\mathrm dx}-(\ln x)y=\sqrt x\ln x}, \]

so \(P(x)=-\ln x\), \(Q(x)=\sqrt x\ln x\).

Example 2 · Page 126

Find the general solution to the differential equation

\[ x\frac{\mathrm dy}{\mathrm dx}+4y=3\sqrt x. \]

Show solution

Divide both sides by \(x\):

\[ \frac{\mathrm dy}{\mathrm dx}+\frac4x y=\frac{3\sqrt x}{x}=\frac3{\sqrt x}. \]

The integrating factor is

\[ R(x)=e^{\int\frac4x\,\mathrm dx}=e^{4\ln x}=x^4. \]

Multiplying through,

\[ x^4\frac{\mathrm dy}{\mathrm dx}+4x^3y=3x^3\sqrt x, \]

so

\[ \frac{\mathrm d}{\mathrm dx}(x^4y)=3x^{7/2}. \]

Integrating,

\[ x^4y=\int3x^{7/2}\,\mathrm dx=\frac23x^{9/2}+C. \]

Hence

\[ \boxed{y=\frac23x^{1/2}+\frac{C}{x^4}=\frac{2\sqrt x}{3}+\frac{C}{x^4}}. \]

Example 3 · Page 126

Find the particular solution to the differential equation

\[ \frac{\mathrm dy}{\mathrm dx}+4x^3y=x^3, \]

for which \(y=0\) when \(x=10\).

Show solution

The integrating factor is

\[ R(x)=e^{\int4x^3\,\mathrm dx}=e^{x^4}. \]

Using \(y=\dfrac1{R(x)}\displaystyle\int R(x)Q(x)\,\mathrm dx\),

\[ y=e^{-x^4}\int x^3e^{x^4}\,\mathrm dx =e^{-x^4}\left(\frac14e^{x^4}+C\right). \]

So the general solution is

\[ y=\frac14+Ce^{-x^4}. \]

Using \(y=0\) when \(x=10\),

\[ 0=\frac14+Ce^{-10^4} \;\Longrightarrow\; C=-\frac14e^{10^4}. \]

Hence

\[ \boxed{y=\frac14\left(1-e^{10^4-x^4}\right)}. \]

Example 4 · Page 130

(a) Express \(e^{4\mathrm ix}-e^{-4\mathrm ix}\) in trigonometric form and simplify your answer.

(b) Express \(\left(e^{3\mathrm ix}+e^{-3\mathrm ix}\right)^2\) in trigonometric form and simplify your answer.

Show solution

(a) Using Euler’s formula \(e^{\mathrm i\theta}=\cos\theta+\mathrm i\sin\theta\),

\[ e^{4\mathrm ix}=\cos4x+\mathrm i\sin4x,\qquad e^{-4\mathrm ix}=\cos4x-\mathrm i\sin4x. \]

Therefore

\[ \boxed{e^{4\mathrm ix}-e^{-4\mathrm ix}=2\mathrm i\sin4x}. \]

(b)

\[ e^{3\mathrm ix}+e^{-3\mathrm ix}=2\cos3x, \]

so

\[ \boxed{\left(e^{3\mathrm ix}+e^{-3\mathrm ix}\right)^2=4\cos^23x}. \]

Example 5 · Page 132

(a) Find the general solution to the differential equation

\[ 4\frac{\mathrm d^2y}{\mathrm dx^2}+12\frac{\mathrm dy}{\mathrm dx}+9y=0. \]

(b) Find the particular solution given that when \(x=0\), \(y=2\) and \(\dfrac{\mathrm dy}{\mathrm dx}=1\).

Show solution

(a) The auxiliary equation is

\[ 4r^2+12r+9=0, \]

so

\[ (2r+3)^2=0 \;\Longrightarrow\; r=-\frac32\ \text{(repeated root)}. \]

The general solution is therefore

\[ \boxed{y=e^{-3x/2}(A+Bx)}. \]

(b) Differentiating,

\[ \frac{\mathrm dy}{\mathrm dx}=e^{-3x/2}\left(-\frac32A+B-\frac32Bx\right). \]

At \(x=0\), \(y=2\) gives \(A=2\). At \(x=0\), \(\dfrac{\mathrm dy}{\mathrm dx}=1\) gives

\[ 1=-\frac32(2)+B \;\Longrightarrow\; B=4. \]

Hence

\[ \boxed{y=2e^{-3x/2}+4xe^{-3x/2}=2e^{-3x/2}(1+2x)}. \]

Example 6 · Page 136

(a) Find the general solution to

\[ \frac{\mathrm d^2y}{\mathrm dx^2}+4y=6x+1. \]

(b) Find the particular solution given that when \(x=0\), \(y=2.75\) and \(\dfrac{\mathrm dy}{\mathrm dx}=1\).

Show solution

(a) The auxiliary equation is \(r^2+4=0\), so \(r=\pm2\mathrm i\), giving the complementary function

\[ y=A\cos2x+B\sin2x. \]

For the particular integral, try \(y=ax+b\):

\[ \frac{\mathrm d^2y}{\mathrm dx^2}=0, \]

so \(4(ax+b)=6x+1\), giving \(a=\dfrac32\), \(b=\dfrac14\). Hence

\[ \boxed{y=A\cos2x+B\sin2x+\frac32x+\frac14}. \]

(b) Using \(x=0\), \(y=2.75\):

\[ 2.75=A+0.25 \;\Longrightarrow\; A=2.5. \]

Differentiating,

\[ \frac{\mathrm dy}{\mathrm dx}=-2A\sin2x+2B\cos2x+\frac32. \]

Using \(x=0\), \(\dfrac{\mathrm dy}{\mathrm dx}=1\):

\[ 1=2B+\frac32 \;\Longrightarrow\; B=-\frac14. \]

Hence

\[ \boxed{y=2.5\cos2x-0.25\sin2x+1.5x+0.25}. \]

Example 7 · Page 137

Find the general solution to

\[ \frac{\mathrm d^2y}{\mathrm dx^2}+\frac{\mathrm dy}{\mathrm dx}-2y=e^x. \]

Show solution

The auxiliary equation is

\[ r^2+r-2=0 \;\Longrightarrow\; (r-1)(r+2)=0, \]

so \(r=1,-2\), giving the complementary function

\[ y=Ae^x+Be^{-2x}. \]

Since \(e^x\) is a term in the complementary function, the particular integral must be \(y=axe^x\). Then

\[ \frac{\mathrm dy}{\mathrm dx}=ae^x+axe^x,\qquad \frac{\mathrm d^2y}{\mathrm dx^2}=2ae^x+axe^x. \]

Substituting into the equation,

\[ 2ae^x+axe^x+ae^x+axe^x-2axe^x=e^x, \]

so \(3ae^x=e^x\), giving \(a=\dfrac13\). Hence

\[ \boxed{y=Ae^x+Be^{-2x}+\frac13xe^x}. \]

Example 8 · Page 139

Find the general solution to

\[ \frac{\mathrm d^2y}{\mathrm dx^2}-4\frac{\mathrm dy}{\mathrm dx}+4y=3e^{2x}. \]

Show solution

The auxiliary equation is

\[ r^2-4r+4=0 \;\Longrightarrow\; (r-2)^2=0, \]

so \(r=2\) (repeated root), giving

\[ y=Ae^{2x}+Bxe^{2x}. \]

Since \(e^{2x}\) and \(xe^{2x}\) are already in the complementary function, the particular integral must be \(y=ax^2e^{2x}\). Then

\[ \frac{\mathrm dy}{\mathrm dx}=2ax^2e^{2x}+2axe^{2x}, \]

\[ \frac{\mathrm d^2y}{\mathrm dx^2}=4ax^2e^{2x}+8axe^{2x}+2ae^{2x}. \]

Substituting,

\[ (4ax^2+8ax+2a)-4(2ax^2+2ax)+4ax^2=3, \]

so \(2a=3\), giving \(a=\dfrac32\). Hence

\[ \boxed{y=Ae^{2x}+Bxe^{2x}+\frac32x^2e^{2x}}. \]

Example 9 · Page 143

Find the general solution of

\[ x\frac{\mathrm dy}{\mathrm dx}+y=x^3y^4 \]

using the substitution \(v=y^{-3}\).

Show solution

With \(v=y^{-3}\),

\[ \frac{\mathrm dv}{\mathrm dx}=-3y^{-4}\frac{\mathrm dy}{\mathrm dx}. \]

Divide the differential equation by \(y^4\):

\[ xy^{-4}\frac{\mathrm dy}{\mathrm dx}+y^{-3}=x^3. \]

Using \(\dfrac{\mathrm dv}{\mathrm dx}=-3y^{-4}\dfrac{\mathrm dy}{\mathrm dx}\),

\[ -\frac{x}{3}\frac{\mathrm dv}{\mathrm dx}+v=x^3. \]

Rearranging,

\[ \frac{\mathrm dv}{\mathrm dx}-\frac3x v=-3x^2. \]

The integrating factor is

\[ R(x)=e^{\int-\frac3x\,\mathrm dx}=x^{-3}. \]

Hence

\[ \frac{\mathrm d}{\mathrm dx}(x^{-3}v)=-3x^{-1}, \]

so

\[ x^{-3}v=-3\ln x+C. \]

Therefore

\[ \boxed{y^{-3}=x^3(C-3\ln x)}. \]

Example 10 · Page 144

Using the substitution \(u=\dfrac yx\), find the particular solution to the differential equation

\[ \frac{\mathrm dy}{\mathrm dx}=\frac{x+y}{x-y}, \]

for which \(x=1\), \(y=1\).

Show solution

With \(u=\dfrac yx\), we have \(y=ux\), so

\[ \frac{\mathrm dy}{\mathrm dx}=u+x\frac{\mathrm du}{\mathrm dx}. \]

Substituting into the equation,

\[ u+x\frac{\mathrm du}{\mathrm dx}=\frac{x+ux}{x-ux}=\frac{1+u}{1-u}. \]

Hence

\[ x\frac{\mathrm du}{\mathrm dx}=\frac{1+u}{1-u}-u=\frac{1+u^2}{1-u}, \]

so

\[ \int\frac{1-u}{1+u^2}\,\mathrm du=\int\frac{\mathrm dx}{x}. \]

Splitting the fraction,

\[ \int\frac{\mathrm du}{1+u^2}-\int\frac{u}{1+u^2}\,\mathrm du=\ln|x|+C. \]

Thus

\[ \tan^{-1}u-\frac12\ln(1+u^2)=\ln|x|+C. \]

Multiplying by \(2\),

\[ 2\tan^{-1}u-\ln(1+u^2)=2\ln|x|+2C. \]

At \(x=1\), \(y=1\), so \(u=1\):

\[ 2\tan^{-1}(1)-\ln2=\frac{\pi}{2}-\ln2. \]

Therefore

\[ \boxed{2\tan^{-1}\left(\frac yx\right)-\ln\left(1+\frac{y^2}{x^2}\right)=\frac{\pi}{2}-\ln2}. \]

Find the solution of the differential equation

\[ \frac{\mathrm dy}{\mathrm dx}+5y=e^{-7x} \]

for which \(y=0\) when \(x=0\). Give your answer in the form \(y=f(x)\).

Show answer and mark scheme

The integrating factor is

\[ e^{\int5\,\mathrm dx}=e^{5x}. \]

Hence

\[ \frac{\mathrm d}{\mathrm dx}\left(ye^{5x}\right)=e^{5x}e^{-7x}=e^{-2x}. \]

Integrating,

\[ ye^{5x}=-\frac12e^{-2x}+C, \]

so

\[ y=-\frac12e^{-7x}+Ce^{-5x}. \]

Using \(y=0\) when \(x=0\),

\[ 0=-\frac12+C \;\Longrightarrow\; C=\frac12. \]

Therefore

\[ \boxed{y=\frac12\left(e^{-5x}-e^{-7x}\right)}. \]

2020 May/June · 9231/23 · Question 1 · 6 marks

Find the general solution of the differential equation

\[ \frac{\mathrm d^2x}{\mathrm dt^2}-8\frac{\mathrm dx}{\mathrm dt}-9x=9e^{8t}. \]

Show answer and mark scheme

The auxiliary equation is

\[ m^2-8m-9=0 \;\Longrightarrow\; (m-9)(m+1)=0, \]

so \(m=9,-1\), giving the complementary function

\[ x=Ae^{9t}+Be^{-t}. \]

For the particular integral, try \(x=ke^{8t}\). Then \(\dot x=8ke^{8t}\) and \(\ddot x=64ke^{8t}\), so

\[ 64ke^{8t}-64ke^{8t}-9ke^{8t}=9e^{8t} \;\Longrightarrow\; k=-1. \]

Hence

\[ \boxed{x=Ae^{9t}+Be^{-t}-e^{8t}}. \]

Source: Cambridge International 9231/23/M/J/2020, Q1.

2020 October/November · 9231/21 & 9231/23 · Question 2 · 7 marks

The variables \(x\) and \(y\) are related by the differential equation

\[ 9\frac{\mathrm d^2y}{\mathrm dx^2}+6\frac{\mathrm dy}{\mathrm dx}+y=3x^2+30x. \]

(a) Find the general solution for \(y\) in terms of \(x\). [6]

(b) State an approximate solution for large positive values of \(x\). [1]

Show answer and mark scheme

(a) The auxiliary equation is

\[ 9m^2+6m+1=0 \;\Longrightarrow\; (3m+1)^2=0, \]

so \(m=-\dfrac13\) (repeated root), giving

\[ y=e^{-x/3}(Ax+B). \]

For the particular integral, try \(y=px^2+qx+r\). Then \(y'=2px+q\) and \(y''=2p\). Substituting,

\[ 18p+6q+12px+px^2+qx+r=3x^2+30x. \]

Equating coefficients gives \(p=3\), \(q=-6\), \(r=-18\). Hence

\[ \boxed{y=e^{-x/3}(Ax+B)+3x^2-6x-18}. \]

(b) For large positive \(x\), the exponential term tends to zero, so

\[ \boxed{y\approx3x^2-6x-18}. \]

Sources: Cambridge International 9231/21/O/N/2020, Q2; 9231/23/O/N/2020, Q2.

2020 October/November · 9231/22 · Question 6 · 11 marks

Find the particular solution of the differential equation

\[ \frac{\mathrm d^2x}{\mathrm dt^2}+8\frac{\mathrm dx}{\mathrm dt}+15x=102\cos3t, \]

given that, when \(t=0\), \(x=1\) and \(\dfrac{\mathrm dx}{\mathrm dt}=0\).

Show answer and mark scheme

The auxiliary equation is

\[ m^2+8m+15=0 \;\Longrightarrow\; (m+3)(m+5)=0, \]

so \(m=-3,-5\), giving

\[ x=Ae^{-3t}+Be^{-5t}. \]

For the particular integral, try \(x=p\cos3t+q\sin3t\). Then

\[ \dot x=-3p\sin3t+3q\cos3t,\qquad \ddot x=-9p\cos3t-9q\sin3t. \]

Substituting and equating coefficients,

\[ (6p-24q)\cos3t+(24p+6q)\sin3t=102\cos3t, \]

so \(p=1\), \(q=-4\). The general solution is

\[ x=Ae^{-3t}+Be^{-5t}+\cos3t-4\sin3t. \]

Using \(x(0)=1\): \(A+B=0\). Using \(\dot x(0)=0\):

\[ -3A-5B-12=0, \]

so \(A=6\), \(B=-6\). Hence

\[ \boxed{x=6e^{-3t}-6e^{-5t}+\cos3t-4\sin3t}. \]

Source: Cambridge International 9231/22/O/N/2020, Q6.

2021 May/June · 9231/23 · Question 5 · 10 marks

The variables \(x\) and \(y\) are related by the differential equation

\[ \frac{\mathrm d^2y}{\mathrm dx^2}-2\frac{\mathrm dy}{\mathrm dx}-3y=4e^{-x}. \]

(a) Find the value of the constant \(k\) such that \(y=kxe^{-x}\) is a particular integral of the differential equation. [4]

(b) Find the solution of the differential equation for which \(y=\dfrac12\) and \(\dfrac{\mathrm dy}{\mathrm dx}=1\) when \(x=0\). [6]

Show answer and mark scheme

(a) For \(y=kxe^{-x}\),

\[ y'=ke^{-x}-kxe^{-x},\qquad y''=-2ke^{-x}+kxe^{-x}. \]

Substituting into \(y''-2y'-3y\),

\[ (-2ke^{-x}+kxe^{-x})-2(ke^{-x}-kxe^{-x})-3kxe^{-x} =-4ke^{-x}. \]

This must equal \(4e^{-x}\), so

\[ \boxed{k=-1}. \]

(b) The auxiliary equation is \(r^2-2r-3=0\), so \(r=3,-1\), giving

\[ y=Ae^{3x}+Be^{-x}-xe^{-x}. \]

Using \(y=\frac12\) at \(x=0\): \(A+B=\frac12\). Differentiating and using \(y'=1\) at \(x=0\):

\[ y'=3Ae^{3x}-Be^{-x}+xe^{-x}-e^{-x}, \]

so \(3A-B-1=1\), i.e. \(3A-B=2\). Hence \(A=\frac58\), \(B=-\frac18\), giving

\[ \boxed{y=\frac58e^{3x}-\frac18e^{-x}-xe^{-x}}. \]

Source: Cambridge International 9231/23/M/J/2021, Q5.

2021 October/November · 9231/21 & 9231/23 · Question 5 · 11 marks

Find the particular solution of the differential equation

\[ \frac{\mathrm d^2y}{\mathrm dx^2}-2\frac{\mathrm dy}{\mathrm dx}+y=4\cos x, \]

given that, when \(x=0\), \(y=-4\) and \(\dfrac{\mathrm dy}{\mathrm dx}=3\).

Show answer and mark scheme

The auxiliary equation is

\[ r^2-2r+1=0 \;\Longrightarrow\; (r-1)^2=0, \]

so \(r=1\) (repeated root), giving

\[ y=e^x(A+Bx). \]

For the particular integral, try \(y=p\cos x+q\sin x\). Then \(y'=-p\sin x+q\cos x\) and \(y''=-p\cos x-q\sin x\). Substituting,

\[ (-p\cos x-q\sin x)-2(-p\sin x+q\cos x)+p\cos x+q\sin x=4\cos x. \]

Equating coefficients gives \(q=2\), \(p=-2\). Hence

\[ y=e^x(A+Bx)-2\cos x+2\sin x. \]

Using \(y=-4\) at \(x=0\): \(A-2=-4\), so \(A=-2\). Using \(y'=3\) at \(x=0\): \(y'=e^x(A+B+Bx)+2\sin x+2\cos x\), so \(A+B+2=3\), giving \(B=3\). Hence

\[ \boxed{y=e^x(-2+3x)-2\cos x+2\sin x}. \]

Sources: Cambridge International 9231/21/O/N/2021, Q5; 9231/23/O/N/2021, Q5.

2022 May/June · 9231/21 & 9231/22 · Question 3 · 11 marks

The variables \(t\) and \(x\) are related by the differential equation

\[ \frac{\mathrm d^2x}{\mathrm dt^2}+\frac{\mathrm dx}{\mathrm dt}+x=t^2+1. \]

(a) Find the general solution for \(x\) in terms of \(t\). [6]

(b) Find the particular solution for which \(x=1\) and \(\dfrac{\mathrm dx}{\mathrm dt}=0\) when \(t=0\). [5]

Show answer and mark scheme

(a) The auxiliary equation is

\[ r^2+r+1=0, \]

with roots \(r=-\dfrac12\pm\dfrac{\mathrm i\sqrt3}{2}\), giving

\[ x=e^{-t/2}\left(A\cos\frac{\sqrt3}{2}t+B\sin\frac{\sqrt3}{2}t\right). \]

For the particular integral, try \(x=pt^2+qt+r\). Then \(x'=2pt+q\), \(x''=2p\). Substituting,

\[ 2p+2pt+q+pt^2+qt+r=t^2+1. \]

Equating coefficients gives \(p=1\), \(q=-2\), \(r=1\). Hence

\[ \boxed{x=e^{-t/2}\left(A\cos\frac{\sqrt3}{2}t+B\sin\frac{\sqrt3}{2}t\right)+t^2-2t+1}. \]

(b) Using \(x=1\) at \(t=0\): \(A+1=1\), so \(A=0\). Then

\[ x=e^{-t/2}B\sin\frac{\sqrt3}{2}t+t^2-2t+1. \]

Differentiating and using \(x'=0\) at \(t=0\):

\[ x'=e^{-t/2}\left(\frac{\sqrt3}{2}B\cos\frac{\sqrt3}{2}t-\frac12B\sin\frac{\sqrt3}{2}t\right)+2t-2, \]

so \(\dfrac{\sqrt3}{2}B-2=0\), giving \(B=\dfrac4{\sqrt3}\). Hence

\[ \boxed{x=\frac4{\sqrt3}e^{-t/2}\sin\frac{\sqrt3}{2}t+t^2-2t+1}. \]

Sources: Cambridge International 9231/21/M/J/2022, Q3; 9231/22/M/J/2022, Q3.

Find the particular solution of the differential equation

\[ \frac{\mathrm d^2x}{\mathrm dt^2}-12\frac{\mathrm dx}{\mathrm dt}+36x=37\sin t, \]

given that, when \(t=0\), \(x=\dfrac{\mathrm dx}{\mathrm dt}=0\).

Show answer and mark scheme

The auxiliary equation is

\[ m^2-12m+36=0 \;\Longrightarrow\; (m-6)^2=0, \]

so \(m=6\) (repeated root), giving

\[ x=e^{6t}(At+B). \]

For the particular integral, try \(x=p\sin t+q\cos t\). Then \(x'=p\cos t-q\sin t\) and \(x''=-p\sin t-q\cos t\). Substituting,

\[ (-p\sin t-q\cos t)-12(p\cos t-q\sin t)+36(p\sin t+q\cos t)=37\sin t. \]

Equating coefficients gives \(p=1\), \(q=0\). Hence

\[ x=e^{6t}(At+B)+\sin t. \]

Using \(x=0\) at \(t=0\): \(B=0\). Using \(x'=0\) at \(t=0\): \(x'=e^{6t}(A+6At)+\cos t\), so \(A+1=0\), giving \(A=-1\). Hence

\[ \boxed{x=-te^{6t}+\sin t}. \]

Find the solution of the differential equation

\[ \frac{\mathrm dy}{\mathrm dx}+3y=\sin x \]

for which \(y=1\) when \(x=0\). Give your answer in the form \(y=f(x)\).

Show answer and mark scheme

The integrating factor is

\[ e^{\int3\,\mathrm dx}=e^{3x}. \]

Hence

\[ \frac{\mathrm d}{\mathrm dx}\left(ye^{3x}\right)=e^{3x}\sin x. \]

Integrating by parts twice,

\[ \int e^{3x}\sin x\,\mathrm dx =\frac{e^{3x}}{10}(3\sin x-\cos x)+C. \]

Therefore

\[ y=\frac1{10}(3\sin x-\cos x)+Ce^{-3x}. \]

Using \(y=1\) when \(x=0\),

\[ 1=-\frac1{10}+C \;\Longrightarrow\; C=\frac{11}{10}. \]

Hence

\[ \boxed{y=\frac1{10}(3\sin x-\cos x)+\frac{11}{10}e^{-3x}}. \]

\[ \frac{\mathrm d^2y}{\mathrm dx^2}+\frac{\mathrm dy}{\mathrm dx}+3y=5e^{x/2}. \]

Find the particular solution of the differential equation

given that, when \(x=0\), \(y=\dfrac{\mathrm dy}{\mathrm dx}=0\).

\[ r^2+4r+3=0 \;\Longrightarrow\; (r+1)(r+3)=0, \]

\[ y=Ae^{-x}+Be^{-3x}. \]

Find the solution of the differential equation

Divide by \(x\):

\[ \frac{\mathrm dy}{\mathrm dx}-\frac1x y=x\tanh^{-1}x. \]

The integrating factor is

\[ e^{\int-\frac1x\,\mathrm dx}=x^{-1}. \]

\[ \frac{\mathrm d}{\mathrm dx}\left(\frac yx\right)=\tanh^{-1}x. \]

Since \(\tanh^{-1}\frac12=\frac12\ln3\),

\[ C=-\frac14\ln3-\frac12\ln\frac34. \]

Hence

\[ \boxed{\frac yx=x\tanh^{-1}x+\frac12\ln(1-x^2)-\frac14\ln3-\frac12\ln\frac34}. \]

Find the general solution of the differential equation

Show answer and mark scheme

\[ r^2+r+1=0, \]

\[ \boxed{y=e^{-x/2}\left(A\cos\frac{\sqrt3}{2}x+B\sin\frac{\sqrt3}{2}x\right)-\frac1{13}\sin2x-\frac5{13}\cos2x}. \]
